D Diffra

描述任务，Diffra 在你的项目里把它做完

桌面端编程 agent：读代码、改代码、跑检查，做完给你看改动。模型用你自己的 API Key。

下载 Windows 版 Windows 10 / 11 · 64 位
  • 改完先过检查自动跑项目的检查命令和安全扫描，没通过就打回去重改。
  • 每一轮都能撤销改动前打检查点，不满意一键退回，不碰你自己的 git。
  • 守住你的数据密钥文件读不到，数据目录改不了，有风险的命令先问你。

第一次安装

安装包还没有代码签名，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。

装好以后，有新版本时应用会在后台下载，重启一下就更新好了。

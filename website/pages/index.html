怎么用

从一句话到能交付的改动

不用写提示词技巧，像跟同事交代任务一样说清楚要什么。

  1. 描述任务

    用平常的话说要做什么。可以拖进文件和截图，或者用 @ 引用代码。

  2. Diffra 动手

    读懂项目、改代码，每次改完自动跑你项目的检查；没通过就自己接着修。

  3. 你来验收

    改了哪些文件、过了哪些检查一目了然。逐处审阅改动，不满意一键撤销。

功能

不只是会写代码

Diffra 把「改完以后」的事也做了：检查、审阅、在浏览器里看效果，交到你手上的是能验收的结果。

改完先过检查，没通过就接着修

Diffra 不靠「看起来改好了」交差。每次改完都会跑你项目里的检查命令，没通过就读回错误继续修。

  • 改动后自动跑快速检查，结束前再跑完整检查
  • 静态检查、安全扫描和规范审查一起把关
  • 「已验证」以实际跑过的结果为准，不听模型自己说

每一处改动都看得见、撤得回

每一轮开始前自动留检查点。改动按文件列出、逐行审阅；不满意就撤销这一轮，不碰你自己的 Git。

  • 改了哪些文件、增删多少行一目了然
  • 逐个文件看差异，和对话放在一起对照
  • 一键撤销这一轮的全部改动

自己打开浏览器，看效果再交差

前端改完，Diffra 会启动开发服务器，在浏览器里打开页面、点一点、看控制台和网络请求，确认真的能用。

  • 内置浏览器，和你自己的浏览器互不干扰
  • 也能用你的 Chrome，带着你的登录状态（需要装 Diffra 浏览器扩展）
  • 打开外部网站前先问你

界面设计也能交给它

设计任务里，Diffra 直接在矢量画布上画界面：布局、文字、图标、真实图片都能放，你可以接着手动改。

  • 内置矢量画布，存成 .fig 文件
  • 风格预设和设计变量，整套界面风格一致
  • 导出 PNG，或者照着设计稿写代码

数据与安全

你的代码，你说了算

Diffra 跑在你的电脑上。它能做什么、不能做什么，由你来定。

数据只发给你选的模型

代码和对话只发给你自己配置的模型服务，不经过 Diffra 的服务器。API Key 用系统的加密存储保存在本机。

有风险的操作先问你

三档权限模式随时切换。危险命令直接拦下；读密钥文件、改受保护的目录，总要先问你。

每一轮都能退回

改动前自动留检查点，撤销只退回这一轮的改动，不影响你自己的 Git 历史。

浏览器也守规矩

打开外部网站、上传文件、在网页里运行脚本之前都会先问；可以设置哪些网站直接打开、哪些不让打开。

常见问题

你可能想知道

收费吗？

公测期间免费。模型的费用由你选的服务商按用量收取，直接付给他们；也可以用智谱、阿里云百炼、Kimi 的编程套餐（Coding Plan）。

支持哪些模型？

内置了 DeepSeek、Kimi、智谱 GLM、阿里云百炼、OpenAI、Anthropic、Google Gemini、OpenRouter 的接入方式，填上 API Key 就能用；其他兼容 OpenAI 或 Anthropic 接口的服务也能自己添加。

我的代码会被上传到哪里？

代码和对话只会发给你自己配置的模型服务，用来完成你交代的任务，不经过 Diffra 的服务器。详见隐私政策。

安装时 Windows 提示「已保护你的电脑」怎么办？

安装包还没有代码签名，Windows SmartScreen 会提示一次：点「更多信息」，再点「仍要运行」。图文说明

有 Mac 版吗？

有。Mac 预览版支持 macOS 12 及以上、Apple 芯片（M 系列）的 Mac，暂不支持 Intel 芯片；还没有经过 Apple 公证，第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，也暂时不会自动更新。下载 Mac 版

怎么更新？

有新版本时 Diffra 会在后台下载，重启一下就更新好了。每个版本改了什么见更新日志。

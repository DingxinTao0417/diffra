在 Windows 上安装

  1. 运行下载好的 Diffra-Setup-版本号.exe。
  2. 安装包还没有代码签名，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。
  3. 按向导选好安装位置（默认装在当前用户的 AppData\Local\Programs\diffra，不需要管理员权限）。
  4. 装好后打开 Diffra，按快速开始接入模型，就能开始第一个任务。

在 Mac 上安装

  1. 打开下载好的 Diffra-版本号-arm64.dmg，把 Diffra 拖进「应用程序」文件夹。
  2. 第一次打开时 macOS 会问「Diffra 是从互联网下载的 App，确定要打开吗？」，点「打开」。Mac 版经过 Apple 公证，不会被拦。
  3. 打开 Diffra，按快速开始接入模型，就能开始第一个任务。快捷键里的 Ctrl 在 Mac 上换成 ⌘。

核对安装包

想确认安装包完整、没被改过，可以算一下它的 SHA-512，和上面列的值比对。Windows 在 PowerShell 里：

[Convert]::ToBase64String([Security.Cryptography.SHA512]::Create().ComputeHash([IO.File]::ReadAllBytes("Diffra-Setup-版本号.exe")))

Mac 在「终端」里：

shasum -a 512 -b Diffra-版本号-arm64.dmg | cut -d' ' -f1 | xxd -r -p | base64

更新和卸载

  • 有新版本时 Diffra 会在后台下载，「设置 → 更新与关于」里点「重启并更新」，或者下次退出时自动装好。每个版本改了什么见更新日志。
  • 装过 Mac 预览版（0.5.2）的：预览版不会自动更新，到这里重新下载一次 dmg，把新的 Diffra 拖进「应用程序」替换旧的，任务记录和设置都还在。第一次打开新版时 macOS 可能问 Diffra 能不能使用钥匙串里的「Diffra Safe Storage」（存着加密 API Key 的密钥），输入开机密码后点「始终允许」。之后的版本就会自动更新了。
  • 卸载：Windows「设置 → 应用」里找到 Diffra 卸载；Mac 把「应用程序」里的 Diffra 移到废纸篓。你的任务记录和设置留在 Windows 的 %APPDATA%\Diffra、Mac 的 ~/Library/Application Support/Diffra，重装后还在；不需要的话可以手动删掉这个文件夹。

1. 安装

从下载页下载安装包并运行。Windows 如果提示「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」，之后有新版本会自动下载，重启就更新好了。Mac 把 dmg 里的 Diffra 拖进「应用程序」就装好了（详细步骤），之后也会自动更新。

2. 接入模型

Diffra 不自带模型，用的是你自己的 API Key，费用直接付给模型服务商。

  1. 打开「设置 → 模型与角色」，点「添加模型服务」。
  2. 在「供应商」里选一个预置的服务，比如 DeepSeek、Kimi、智谱、阿里云百炼、OpenAI、Anthropic、Google Gemini；用编程套餐的，选对应的 Coding Plan。其他兼容 OpenAI 或 Anthropic 接口的服务选「自定义」，自己填地址。
  3. 填上 API Key，点「下一步」，确认模型能力后点「校验并添加模型」。Diffra 会真的调用一次，确认能用。
  4. 在「角色」里，把「编码」选成刚加的模型。「规划」和「备用」可以先不设。

API Key 用系统的加密存储（Windows 的数据保护、Mac 的钥匙串）保存在你的电脑上，只会发给对应的服务商。

3. 第一个任务

  1. 回到首页，在输入框下面的项目下拉里点「选择文件夹…」，选你的项目。
  2. 用平常的话描述要做什么，比如「给待办加上优先级，列表按优先级排序」。可以把文件、截图拖进输入框，或者用 @ 引用文件。
  3. 点发送（或按 Ctrl + Enter）。Diffra 会读项目、改代码，每次改完跑一遍检查。

检查命令在任务页右侧「任务监控」的「检查」里设置：Diffra 能从项目里检测出来（比如 package.json 里的 test 脚本），你确认、试运行一次后保存；也可以点「编辑检查命令」自己写。设好以后每次改完都会跑，没通过它会读回错误接着修。

4. 审阅和撤销

任务做完会出现「本轮交付」：改了哪些文件、增删多少行、过了哪些检查。

  • 点「审阅改动」，逐个文件看差异。
  • 不满意就点「撤销改动」，这一轮的改动全部退回。撤销用的是 Diffra 自己的检查点，不碰你的 Git。
  • 任务页右侧的「任务监控」随时显示进度、改动的文件和检查结果。

5. 权限模式

输入框左下角可以切换权限模式，也能在「设置 → 命令权限」里改默认值。

模式行为
每次询问只读命令和检查命令自动执行，其余命令执行前都问你。
自动审批普通命令自动执行；涉及密钥文件、禁写目录、git 推送或重置、安装依赖、下载、递归删除时仍然问你。
完全访问命令不再询问。危险命令清单、受保护文件和禁写目录照旧拦截。

6. 浏览器

前端项目里，Diffra 会自己启动开发服务器，在任务页右侧的内置浏览器里打开页面，点一点、看控制台和网络请求，确认改动真的能用。打开外部网站前会先问你；「设置 → 浏览器与电脑操控」里可以列出直接打开、不让打开的网站。

想让它用你自己的 Chrome 或 Edge（带着你的登录状态），在「设置 → 浏览器与电脑操控」里选「我的 Chrome」，再装上 Diffra 浏览器扩展。扩展正在上架应用商店，上架后会在这里给出安装链接。

7. 设计任务

点侧栏的「设计」进入设计首页，描述你要的界面。Diffra 会在矢量画布上画出来：布局、文字、图标、网上的真实图片都能放，你可以在画布上接着改，或者导出 PNG。

8. 设备连接

同一个局域网里（连着同一个路由器）的两台电脑都装了 Diffra，就能在一台上查看、操作另一台开放给它的任务，发消息和图片，还能同步待办。两台电脑直接连接，不经过任何服务器。默认关闭，两边的 Diffra 要是同一个版本。

  1. 在要被连接的电脑上，打开「设置 → 设备连接」，切到「允许连接本机」，打开「允许连接本机」开关。Windows 第一次会问要不要让 Diffra 使用网络，选允许专用网络。
  2. 点「生成配对码」，屏幕上会出现 6 位数字，10 分钟内有效，输错 3 次作废。
  3. 在另一台电脑上打开「设置 → 设备连接 → 连接其他设备」，点「添加设备」，在局域网设备列表里选中对方。先核对列表里的证书指纹和对方页面上的一样，再输入配对码。
  4. 被连接的电脑上会弹出请求：核对对方的名称和指纹，选开放哪些项目（每个项目可以选「可查看」「可查看和操作」或「完全控制」），要不要同步待办，再点「允许」。

配好以后，对方开放的项目会出现在侧栏的项目列表里，用设备图标标出。被连接的电脑可以随时在「已授权设备」里修改授权或撤销，撤销后对方马上断开。

9. 快捷键

操作快捷键
新任务Ctrl + N
搜索任务Ctrl + K
发送消息Ctrl + Enter
收起或展开侧栏Ctrl + B
打开或收起终端（任务页）Ctrl + `
打开设置Ctrl + ,

Mac 上把 Ctrl 换成 ⌘，只有终端还是 ⌃ + `；后退、前进是 ⌘ + [、⌘ + ]。

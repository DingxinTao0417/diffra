隐私政策

Diffra 处理哪些数据、发到哪里、官网记录什么。

最后更新：2026 年 11 月 15 日

Diffra 由个人开发者艾特（以下称「我」）开发和维护。本政策适用于 Diffra 桌面应用、官网 diffra.dev 和更新服务 update.diffra.dev。Diffra 浏览器扩展另有单独的说明。

一句话说清楚

Diffra 跑在你的电脑上。你的代码和对话只发给你自己配置的模型服务，以及你打开设备连接后在局域网里配对、授权过的设备，都不经过我的服务器；我的服务器只提供更新、扩展目录和官网，只记录普通的访问日志。

保存在你电脑上的数据

  • 任务记录、对话、设置、设计稿、待办等，保存在本机的 %APPDATA%\Diffra（Mac 上是 ~/Library/Application Support/Diffra）。卸载 Diffra 不会删除它们，你可以随时手动删掉这个文件夹。
  • 你填的模型 API Key 用系统的加密存储加密后保存在本机：Windows 上用系统的数据保护，只有你当前的 Windows 账户能解开；Mac 上加密用的密钥放在你的钥匙串里，只有你的 Mac 账户能取用。
  • 改动前打的检查点保存在本机，只用来撤销改动。

发给模型服务商的数据

完成你交代的任务时，Diffra 会把需要的内容（你的指令、相关的代码和文件内容、命令输出、截图等）发给你在 Diffra 里配置的模型服务商，用的是你自己的 API Key。这些数据由服务商按他们的隐私政策处理，我接触不到。请在选择服务商前阅读他们的条款。

按你的要求访问的网络

你让智能体打开网页、下载图片、连接 MCP 服务器时，Diffra 会直接访问对应的网站或服务。打开外部网站、上传文件之前，Diffra 会按你设置的权限模式先问你。

设备连接（局域网，默认关闭）

设备连接让同一个局域网里两台电脑上的 Diffra 直接连接，不经过任何服务器。它默认关闭，你在「设置 → 设备连接」里打开后才会用到网络。

  • 在局域网里广播的内容：打开「允许连接本机」后，Diffra 每 3 秒向局域网发一条发现消息，内容是本机的设备 ID、名称（默认是这台电脑的计算机名，可以在设置里改）、连接端口、证书指纹、是不是正在等配对和协议版本。同一个局域网里的设备都能收到。关掉这个开关就不再发送。
  • 传给对方设备的内容：配对时由你选开放哪些项目、给什么权限。对方能看到这些项目里的任务、对话、改动和图片，按权限发消息、操作任务；给了「完全控制」还能打开本机的终端；选了同步待办，两台电脑的待办会合在一起。这些内容只在两台电脑之间传，只连局域网地址，连接用 TLS 加密，内容另外端到端加密。
  • 保存在本机的内容：本机的设备密钥和证书私钥用系统的加密存储加密后保存；配对的设备、授权和操作记录（配对、授权的变化、对方远程做的操作）保存在本机数据目录，不上传到任何地方。
  • 你可以随时修改或撤销某台设备的授权，或者「重置本机身份」，让所有配对作废。

检查更新

Diffra 每次启动以及之后每 4 小时，会向 update.diffra.dev 查询有没有新版本，有的话下载更新包。这些请求只包含普通的网络请求信息（IP 地址、请求时间、客户端标识），不包含你的代码、对话、文件或 API Key。这些请求会出现在下面说的服务器访问日志里。

扩展目录

打开 Diffra 的「扩展」页时，Diffra 会向 diffra.dev 查询可安装的 MCP 服务器和插件清单有没有更新，一小时内最多查一次；点「检查更新」会马上查。这些请求同样只包含普通的网络请求信息，不包含你的代码、对话、文件或 API Key，也会出现在服务器访问日志里。

官网

  • 官网不使用 Cookie，不加载任何第三方统计、广告或追踪脚本。
  • 官网页面会从更新服务读取最新版本号和安装包大小，用来显示在页面上。

服务器访问日志和统计

官网和更新服务部署在同一台位于美国的服务器上。和几乎所有网站一样，服务器会记录访问日志，每条包括：IP 地址、访问时间、请求的页面或文件、来源页面（Referer）、浏览器或客户端标识（User-Agent）、响应状态和大小。

  • 用途：统计官网访问量、安装包下载次数和大致的在用人数（按检查更新的次数估算），以及排查故障和防范攻击。
  • 保存期限：保留 180 天，之后自动删除。我只在本机查看汇总后的统计报表，报表不公开。
  • 不做的事：不用这些日志识别你是谁，不和其他数据关联，不出售，也不提供给任何第三方，法律要求的情况除外。

我不做的事

  • Diffra 应用里没有任何使用统计、崩溃上报或广告追踪；
  • 不收集你的代码、对话、文件和 API Key；
  • 不出售或转让任何数据。

你的选择

  • 删除本机数据：删掉 %APPDATA%\Diffra（Mac 上是 ~/Library/Application Support/Diffra）文件夹即可。
  • 如果你希望删除服务器日志里和你的 IP 地址有关的记录，或者对本政策有疑问，请发邮件告诉我。

政策变更

本政策有变化时，我会更新这个页面和上面的日期；重要的变化会在更新日志里说明。

隐私政策

Diffra 处理哪些数据、发到哪里、官网记录什么。

最后更新：2026 年 11 月 11 日

Diffra 由个人开发者艾特（以下称「我」）开发和维护。本政策适用于 Diffra 桌面应用、官网 diffra.dev、更新服务 update.diffra.dev 和设备连接的中转服务 relay.diffra.dev。Diffra 浏览器扩展另有单独的说明。

一句话说清楚

Diffra 跑在你的电脑上。你的代码和对话只发给你自己配置的模型服务，不经过我的服务器；我的服务器只提供更新和官网，只记录普通的访问日志。只有你打开了「设备连接」，你和你配对的设备之间的内容才会经我的中转服务器转发，转发的是端到端加密后的数据，服务器不解密、不保存。

保存在你电脑上的数据

  • 任务记录、对话、设置、设计稿、待办等，保存在本机的 %APPDATA%\Diffra。卸载 Diffra 不会删除它们，你可以随时手动删掉这个文件夹。
  • 你填的模型 API Key 用 Windows 系统的加密存储加密后保存在本机，只有你当前的 Windows 账户能解开。
  • 改动前打的检查点保存在本机，只用来撤销改动。

发给模型服务商的数据

完成你交代的任务时，Diffra 会把需要的内容（你的指令、相关的代码和文件内容、命令输出、截图等）发给你在 Diffra 里配置的模型服务商，用的是你自己的 API Key。这些数据由服务商按他们的隐私政策处理，我接触不到。请在选择服务商前阅读他们的条款。

按你的要求访问的网络

你让智能体打开网页、下载图片、连接 MCP 服务器时，Diffra 会直接访问对应的网站或服务。打开外部网站、上传文件之前，Diffra 会按你设置的权限模式先问你。

设备连接（默认关闭）

「设置 → 设备连接」可以让另一台电脑上的 Diffra 查看、操作你开放给它的项目里的任务。不打开就不会连中转服务器，和没有这个功能时完全一样。

  • 怎么传：两台设备都连到 relay.diffra.dev，由它转发。内容在两台设备之间用 Noise 协议端到端加密，中转服务器只转发、不解密，也不保存，对方不在线时不替你暂存。
  • 服务器能看到的：设备 ID（由设备自己生成的公钥算出来的一串随机字符，不含你的名字和电脑信息）、IP 地址、连接和断开的时间、转发的数据量，以及哪些设备彼此配对了。
  • 中转的日志：只记连接、断开（设备 ID 的前 8 位和 IP 地址）和出错；中转的访问日志记录每次连接的 IP 地址、时间、客户端标识和传输的字节数。这些日志和官网、更新服务的日志分开存，保留 14 天后自动删除，不记任何转发的内容，也不做统计。
  • 对方能看到的：只有你在配对时、或之后在设置里开放的项目里的任务记录。发出去之前会尽力去掉密钥、密码这类内容，可能含密钥的文件不发；提问里带的图片压缩成小图再发，工具输出里的截图不发；但这只能尽力，真正的边界是你开放了哪些项目。对方那边的副本只在内存里，不写盘。
  • 「可查看和操作」：等于让对方以你的 Windows 账户在你的电脑上运行命令。对方发的任务用你配置的模型和 API Key，费用算在你这边。只开放给你信任的人；能操作你电脑的设备在线时，窗口顶部会一直提示，随时可以断开。
  • 本机保存的：设备连接用的密钥用 Windows 系统的加密存储加密后保存在 %APPDATA%\Diffra\remote；配对、授权、撤销和远程设备做过的操作（不含消息内容）记在同一个文件夹的操作记录里。

检查更新

Diffra 每次启动以及之后每 4 小时，会向 update.diffra.dev 查询有没有新版本，有的话下载更新包。这些请求只包含普通的网络请求信息（IP 地址、请求时间、客户端标识），不包含你的代码、对话、文件或 API Key。这些请求会出现在下面说的服务器访问日志里。

官网

  • 官网不使用 Cookie，不加载任何第三方统计、广告或追踪脚本。
  • 官网页面会从更新服务读取最新版本号和安装包大小，用来显示在页面上。

服务器访问日志和统计

官网、更新服务和设备连接的中转部署在同一台位于美国的服务器上。中转的日志另见上面「设备连接」一节，保留 14 天；下面说的是官网和更新服务的访问日志。和几乎所有网站一样，服务器会记录访问日志，每条包括：IP 地址、访问时间、请求的页面或文件、来源页面（Referer）、浏览器或客户端标识（User-Agent）、响应状态和大小。

  • 用途：统计官网访问量、安装包下载次数和大致的在用人数（按检查更新的次数估算），以及排查故障和防范攻击。
  • 保存期限：保留 180 天，之后自动删除。我只在本机查看汇总后的统计报表，报表不公开。
  • 不做的事：不用这些日志识别你是谁，不和其他数据关联，不出售，也不提供给任何第三方，法律要求的情况除外。

我不做的事

  • Diffra 应用里没有任何使用统计、崩溃上报或广告追踪，中转服务也不做统计；
  • 不收集你的代码、对话、文件和 API Key；设备连接转发的内容是加密的，服务器不解密；
  • 不出售或转让任何数据。

你的选择

  • 删除本机数据：删掉 %APPDATA%\Diffra 文件夹即可。
  • 设备连接：关掉「允许连接本机」，所有授权的设备马上看到你离线；也可以单独撤销某台设备。
  • 如果你希望删除服务器日志里和你的 IP 地址有关的记录，或者对本政策有疑问，请发邮件告诉我。

政策变更

本政策有变化时，我会更新这个页面和上面的日期；重要的变化会在更新日志里说明。

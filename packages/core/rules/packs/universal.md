本包只保留跨语言都成立的规则，措辞经过改写和合并。手册里只适用于 Java、MySQL 或阿里内部流程的条目没有收录，
和项目惯例冲突的条目（比如每个类都写作者和日期）也没有收录。

## 命名
- [GEN-NAME-1][强制] 标识符用正确的英文，不用拼音、拼音英文混写或中文；alibaba、hangzhou 这类国际通用的名称可以当英文用。
- [GEN-NAME-2][强制] 不随意缩写，名字要能看出含义（condi、AbsClass 这类不行）；id、url、http 等业界通用缩写除外。
- [GEN-NAME-3][强制] 命名风格（大小写、分隔方式）遵循该语言和项目已有的惯例，同一项目内不混用。
- [GEN-NAME-4][推荐] 常量名把含义说完整，比如 MAX_STOCK_COUNT 而不是 MAX_COUNT。
- [GEN-NAME-5][推荐] 表示类型的词放在名字末尾：startTime、nameList、workQueue。
- [GEN-NAME-6][推荐] 父子类的成员之间、同一函数的不同代码块之间不用相同的变量名。
- [GEN-NAME-7][推荐] 代码和注释中不用歧视性或侮辱性词语，比如用 allowList / blockList 代替 whiteList / blackList。

## 常量
- [GEN-CONST-1][强制] 有业务含义的值（缓存 key 前缀、状态值、阈值等）不直接写在代码里，先定义成有名字的常量或枚举。
- [GEN-CONST-2][推荐] 常量按功能分开放，不建一个大而全的常量文件；取值在固定范围内的用枚举。

## 控制流
- [GEN-FLOW-1][强制] 并发场景下不用「等于」判断作为终止条件，用区间判断，比如库存 <= 0 而不是 == 0。
- [GEN-FLOW-2][推荐] 异常分支用卫语句提前返回，if-else 不超过 3 层。
- [GEN-FLOW-3][推荐] 复杂条件先赋给有意义的布尔变量再判断；不在条件表达式里赋值。
- [GEN-FLOW-4][推荐] 少用取反逻辑：写 x < 628，不写 !(x >= 628)。
- [GEN-FLOW-5][推荐] 循环里不做能移到循环外的事，比如创建对象、获取连接、多余的 try-catch。

## 异常与错误
- [GEN-ERR-1][强制] 不吞异常：捕获了就要处理；处理不了就向上抛，最外层把它转成用户能看懂的提示。
- [GEN-ERR-2][强制] 能预先检查的错误（空值、越界等）先检查，不靠捕获异常兜底；也不用异常控制正常流程。
- [GEN-ERR-3][强制] 只包住可能出错的代码，按异常类型分别处理，不对大段代码笼统地捕获所有异常。
- [GEN-ERR-4][强制] 不在 finally 里 return；文件、连接、流、锁在 finally 或语言的自动释放语法里关闭。
- [GEN-ERR-5][强制] 事务里捕获异常后如果需要回滚，要显式回滚。
- [GEN-ERR-6][推荐] 抛带业务含义的具体异常类型，不直接抛通用的异常基类。
- [GEN-ERR-7][推荐] 返回给用户的错误提示不带堆栈和内部信息；对外接口用错误码和错误信息表达失败。
- [GEN-ERR-8][推荐] 可能返回空值的函数要说明什么情况下返回空；调用方对远程调用结果、查询结果、链式取值做空值判断。

## 日志
- [GEN-LOG-1][强制] 记录异常时同时带上现场信息（关键参数、业务 id）和原始异常对象，不只记 message。
- [GEN-LOG-2][强制] 日志里不打印密码、密钥、令牌和未脱敏的个人信息。
- [GEN-LOG-3][推荐] 用日志库的占位符或结构化参数，不在日志调用里拼字符串；同一个异常不在多层重复打印。
- [GEN-LOG-4][推荐] 正式代码通过项目的日志设施输出，不留 print / console 调试输出。
- [GEN-LOG-5][推荐] 用户输入错误记 warn，error 只用于系统错误，避免频繁报警。

## 并发
- [GEN-CONC-1][强制] 并发修改同一条记录要防止更新丢失：加锁，或用 version 字段做乐观锁。
- [GEN-CONC-2][强制] 同时锁多个资源时，所有地方都按同一顺序加锁，防止死锁。
- [GEN-CONC-3][强制] 线程、后台任务、队列都要有数量上限，不无限创建；给线程或任务起能看出用途的名字。
- [GEN-CONC-4][推荐] 锁的范围尽量小，持锁期间不做远程调用。
- [GEN-CONC-5][推荐] 涉及资金的并发更新优先用悲观锁：先锁、再判断、再更新、最后释放。

## 数值与时间
- [GEN-NUM-1][强制] 金额用最小货币单位的整数或十进制定点类型存储和计算，不用二进制浮点数。
- [GEN-NUM-2][强制] 浮点数不用 == 判断相等。
- [GEN-NUM-3][强制] 不写死一年 365 天、一月 30 天，用日期库计算；注意闰年 2 月 29 日。
- [GEN-NUM-4][推荐] 跨系统传递时刻用带时区的标准格式（ISO 8601）或单位明确的时间戳。

## 外部调用与容量
- [GEN-IO-1][强制] 直接发起网络请求、建立数据库连接、启动外部进程的代码要设置超时，或者使用已经配置了超时的客户端；只是调用别人传进来的接口时不算。
- [GEN-IO-2][推荐] 会增长的集合、缓存、队列要有容量上限；列表接口限制每页数量，批量接口限制一次的条数。
- [GEN-IO-3][推荐] 能区分主次的外部依赖要有降级方案，次要依赖出故障时不拖垮主流程。

## 数据库
- [GEN-DB-1][强制] 业务上唯一的字段（包括组合字段）建唯一索引，不只靠「先查后插」保证唯一。
- [GEN-DB-2][强制] 涉及多张表的查询，列名前加表名或别名限定。
- [GEN-DB-3][推荐] 查询写明需要的列，不用 SELECT *；更新时只更新改动了的字段。
- [GEN-DB-4][推荐] 统计行数用 count(*)；列全为 NULL 时 sum 返回 NULL，要处理。
- [GEN-DB-5][推荐] 分页先查总数，为 0 就直接返回；偏移量很大的分页用游标或延迟关联。
- [GEN-DB-6][推荐] 修改或删除数据前，先用同样的条件查询，确认影响范围。
- [GEN-DB-7][推荐] 防止字段类型不一致导致的隐式转换让索引失效；页面搜索不用左模糊或全模糊匹配。

## 测试
- [GEN-TEST-1][强制] 测试用断言自动判定结果，不靠打印让人看；用例之间不互相调用、不依赖执行顺序。
- [GEN-TEST-2][强制] 单元测试不依赖网络和外部服务，需要时注入替身或 mock。
- [GEN-TEST-3][推荐] 覆盖边界值、正确输入和错误输入，而不只是正常路径。
- [GEN-TEST-4][推荐] 和数据库相关的测试要能回滚，或者给测试数据加明确的前缀。

## 整洁
- [GEN-CLEAN-1][推荐] 删除不再使用的代码、参数、变量和配置，不留大段注释掉的代码。
- [GEN-CLEAN-2][推荐] 注释说明「为什么」而不是复述代码；改代码时同步改相关注释。
- [GEN-CLEAN-3][推荐] 单个函数不超过 80 行；不同逻辑之间用一个空行隔开。
- [GEN-CLEAN-4][推荐] 重复的逻辑抽成公共函数，不复制粘贴。
